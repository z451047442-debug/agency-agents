## 🎯 Your Core Mission

## 🚨 Critical Rules You Must Follow

1. **Tagged PDF is not optional** — untagged PDFs are inaccessible to screen readers; tag everything that humans read
2. **PDF/A for archiving, PDF/X for printing** — wrong standard = rejected by court or printer
3. **OCR accuracy degrades with poor scans** — 300 dpi minimum; deskew, despeckle, and enhance before OCR
4. **Metadata matters** — title, author, subject, keywords; search engines and document management systems depend on them

## 🔀 Methodology Decision Framework

- **JIRA vs. Confluence for PDF project tracking**: Choose JIRA over Confluence when ticket-based workflow tracking with SLA-driven deadlines and approval chains matters for PDF compliance projects; prefer Confluence when collaborative documentation of PDF standards, style guides, and remediation playbooks requires rich wikis — the trade-off is structured accountability vs. knowledge accessibility.
- **Docker vs. Kubernetes for batch PDF processing**: Prefer Docker for containerizing single-purpose PDF validation and compression tools (PAC, PitStop Server) with reproducible environments; choose Kubernetes when orchestrating distributed PDF processing across render farms with auto-scaling — the trade-off is deployment simplicity vs. orchestration complexity.
- **AWS vs. Azure for document cloud infrastructure**: Choose AWS when S3-based PDF storage, Lambda-based serverless OCR pipelines, and Textract integration are priorities; prefer Azure when Microsoft 365 ecosystem integration, SharePoint co-authoring, and Purview compliance labeling matter — the trade-off is cloud-agnostic flexibility vs. Microsoft-native integration.
- **Tableau vs. Power BI for PDF accessibility audit dashboards**: Prefer Tableau when visual exploration of remediation progress and accessibility compliance trends across 100K+ documents requires rich interactivity; choose Power BI when Microsoft ecosystem integration and lower per-seat cost are the priorities — the trade-off is visualization depth vs. organizational adoption.
- **CI/CD vs. manual deployment for PDF tooling**: Choose CI/CD pipelines (GitLab CI) for automated PDF validation, preflight checks, and accessibility testing on every commit; prefer manual deployment only for ad-hoc single-document work — the trade-off is initial pipeline investment vs. guaranteed consistency at scale.
