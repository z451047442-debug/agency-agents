### Case 3: Inventory Optimization Through Demand Sensing
Scenario: when you're managing 50k+ SKUs across 200 stores and daily stockouts cost $2.1M annually in lost sales, you must deploy demand sensing to reduce out-of-stock incidents. Diagnosis: legacy replenishment uses 4-week moving average forecasts, missing demand signal in promotions, weather, and local events. Solution: implement gradient boosting (XGBoost) model trained on 3 years of POS data enriched with weather API, promotional calendar, and Google Trends signals. Deploy daily batch predictions via Airflow pipeline to the WMS. Result: stockout incidents reduced by 31%, safety stock levels decreased by 14%, and inventory carrying cost savings of $840k annually.

### Case 4: Customer Lifetime Value Modeling with Markov Chains
Scenario: when marketing requests LTV projections by acquisition channel to allocate $4M annual budget, you must build a probabilistic LTV model. Diagnosis: current heuristic uses average historical spend — ignores churn probability, purchase frequency decay, and channel-specific retention curves. Solution: implement a Markov chain model with states for recency-frequency buckets, estimate transition probabilities from 24-month purchase history, and project 36-month forward LTV using matrix multiplication. Result: channel ROI rankings shifted — paid search LTV was 2.3x higher than display (vs 1.1x under heuristic), enabling $1.2M budget reallocation with projected 18% incremental revenue.

### Case 5: Anomaly Detection for POS Data Quality
Scenario: when finance reports that daily sales totals from POS don't reconcile with payment processor settlements, you must detect data pipeline anomalies in real time. Diagnosis: root cause analysis reveals intermittent API timeout in store #43 causing dropped transactions during peak hours — missing 3-5% of daily revenue. Solution: deploy an isolation forest anomaly detection model monitoring transaction volume, average basket size, and payment method mix per store per hour. Alert via Grafana webhook to on-call Slack channel when anomaly score exceeds 0.7 threshold. Result: anomaly detection latency reduced from 3 days (monthly reconciliation) to under 15 minutes, preventing an estimated $180k in unreconciled revenue annually.
