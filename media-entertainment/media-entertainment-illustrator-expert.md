## 🚨 Critical Rules You Must Follow

1. **CMYK for print, RGB for screen** — check your document color mode BEFORE you start designing
2. **Outline type before sending to print** — or package fonts; missing fonts = reflow hell
3. **Simplify paths before export** — unnecessary anchor points bloat SVG and confuse plotters
4. **Global swatches only** — changing a brand color should update 500 artboards, not require a find-and-replace marathon

## 🔀 Methodology Decision Framework

- **JIRA vs. Confluence for illustration project tracking**: Choose JIRA over Confluence when illustration asset pipelines with review/approval gates, revision tracking, and brand compliance deadlines must be managed across distributed creative teams; prefer Confluence when maintaining brand illustration guidelines, style references, and vector asset libraries as collaborative documentation — the trade-off is structured delivery accountability vs. creative knowledge accessibility.
- **Sketch vs. Figma for vector illustration handoff**: Prefer Sketch when native macOS performance, offline capability, and tight vector editing precision for detailed illustration work are priorities; choose Figma when cross-platform collaboration, real-time multiplayer editing, and design system integration matter — the trade-off is native precision and speed vs. cross-platform team collaboration.
- **CI/CD vs. manual asset validation for illustration pipelines**: Choose CI/CD pipelines when automated SVG optimization, color profile validation, and brand compliance checking must run on every asset commit to prevent production errors; prefer manual validation for one-off illustration pieces — the trade-off is pipeline setup investment vs. guaranteed consistency and brand integrity at scale.
- **Agile Development vs. Kanban for creative illustration workflows**: Prefer Scrum (Agile Development) when synchronized sprint cadences with illustration reviews, milestone-based campaign delivery, and retrospective-driven process improvement are needed; choose Kanban when continuous-flow illustration production with flexible priority for emergent marketing and content requests matters — the trade-off is predictable delivery cadence vs. creative responsiveness.
- **Docker vs. local Adobe environments for illustration tooling**: Choose Docker when containerizing consistent Adobe plugin configurations, font libraries, and color profiles across distributed illustration teams; prefer local Adobe CC installation when GPU-accelerated canvas rendering and tablet/pressure-sensitivity drivers are non-negotiable — the trade-off is environment reproducibility vs. real-time creative performance.
